# Profile Images

프로필 이미지 파일 위치입니다.

## 필요한 파일

- `player.png` - 플레이어 프로필 (불독 심볼)
- `opponent1.png` - 상대1 프로필
- `opponent2.png` - 상대2 프로필
- `small-blind.png` - 스몰 블라인드 프로필
- `big-blind.png` - 빅 블라인드 프로필
- `dealer.png` - 딜러 프로필

## 권장 사양

- 크기: 128x128px 이상
- 형식: PNG (투명 배경 권장)
- 스타일: 동그란 프레임에 맞는 정사각형

이미지가 없으면 기본 폴백 텍스트 (P, O1, O2, SB, BB, D)가 표시됩니다.
